# Zachyn — Portfolio

Personal portfolio site: a single self-contained `index.html` (no build step, no dependencies).

## Before publishing
Open `index.html` and replace the placeholders in the Contact section:
- `your.email@example.com`
- `https://www.linkedin.com/in/your-profile`

## Publish on GitHub Pages
1. Create a new public repository (for a free root URL, name it `<your-username>.github.io`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to Settings → Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute or two the site is live at `https://<your-username>.github.io/`.
